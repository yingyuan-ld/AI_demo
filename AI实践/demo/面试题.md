

# 面试题目：TRON 链上资金分析溯源平台（前端）

# 一、题目背景
你需要开发一款前端产品，对标 Chainalysis Reactor 的核心资金溯源功能。https://www.chainalysis.com/product/reactor/ 这是他们官网. Reactor 通过网状图将链上地址和交易可视化为可交互的节点-边结构，支持无限层级展开追踪资金流向，并关联实体标签（交易所、混币器、受制裁地址等）。

你的任务是使用 AI 辅助开发工具，仅开发前端，构建一个 TRON 地址资金溯源分析平台的原型。后端数据自己 mock 即可。



# 二、核心功能要求

**核心功能至少有以下几种, 但不限增加新功能**

2.1 地址输入与溯源分析
页面顶部提供一个醒目的搜索输入框，用户输入一个 TRON 地址（以 T 开头，34 位，Base58 格式）即可触发溯源分析。

输入框需包含地址格式校验，非法地址给出明确的错误提示。

输入有效地址后，主区域展示以该地址为根节点的资金流向网状图。



2.2 网状图可视化
以网图渲染节点和边，节点代表 TRON 地址，边代表 TRC-20 转账关系。

节点视觉编码：不同类型的地址应有视觉区分（如：普通钱包、交易所、混币器、受制裁地址、合约地址），可通过颜色、图标或边框样式区分.

边上可显示转账金额和代币类型。

交互操作：支持缩放、平移、拖拽节点, 点击节点展开与折叠

节点展开：点击某个节点可展开其下一层交易对手展示资金的多级流转路径。



2.3 节点详情查看
点击任意节点，侧边栏或弹出面板展示该地址的详细信息，至少包含：

地址哈希（可复制）

地址标签（交易所官方, 交易所用户）

风险评分（0-100，配合颜色指示）

余额（TRX / USDT）

交易计数（转入/转出笔数）

首次出现时间

关联的已知实体信息



2.4 关系详情查看
点击任意边，展示该笔转账关系的详情：

交易哈希（TxID）

转账金额与代币类型

时间戳

发送方 → 接收方地址

该笔交易的风险标记（如“与混币器直接交互”）



2.5 数据 Mock 要求
你需要自行设计 mock 数据结构，但需满足以下条件：

至少包含 3 层深度的资金流转关系（根地址 → 一级对手方 → 二级对手方 → 三级对手方）。

总节点数不少于 20 个，边数不少于 25 条。

至少包含 2 种实体类型（如交易所地址、普通钱包），且至少一个节点带有风险标记。

Mock 数据应模拟真实 TRON 场景：USDT（TRC-20）为主要流转资产，转账金额从几十 USDT 到数百万 USDT 不等，时间跨度覆盖最近 30 天。



# 三、UI/UX 设计要求
3.1 整体布局
参考 Chainalysis Reactor 的布局逻辑，或者自行设计一款.

可运行的本地原型（npm run dev 或直接打开 HTML 文件即可运行）。
